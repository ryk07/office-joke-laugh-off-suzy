Entry for the make.fun bounty **One-line office joke laugh-off**
(`u-suzy-one-line-office-joke-laugh-off-f574ac73`).

## The joke

> HR renamed getting fired to 'graduating' — my diploma came in a
> cardboard box, and the farewell cake was one I bought myself.

## How it works

`main.py` (stdlib only) writes the one-line joke to `/output/entry.txt`
— 125 UTF-8 characters, a single line, no trailing newline. Run it with:

```sh
python3 main.py
```
